# mhc_pre

## 1. 测试方法

- 在海光bw1000上进行测试。共三轮独立进程，每轮每版 20 次预热、50 个有效 GPU-event 样本。
- 每个 GPU-event 窗口重放 128 次 kernel，event 时间除以 128。编译、分配、参考计算、graph capture 及重置不计时；结果为热/复用工作集时延。
- 下表合并每版全部 150 个样本；时间单位为 μs，加速比为 TLE P50 / Gluon 优化版 P50。

## 2. 改变了哪些 op 的 layout

**算子顺序：**

1. **Residual RMS 统计 → GEMM 结果归一化与仿射变换。**
2. **Pre/Post 分支做 Sigmoid；Comb 分支做 Softmax → Sinkhorn。**
3. **Pre mix × Residual → HC 加权求和 → Layer input 写回，同时输出 Post/Comb mix。**

改变的是 **HC=4 的 Residual RMS 统计和最后的 Residual 加权求和**：两遍 Residual 读取、平方/归约输入、加权计算及 Layer input 写回共用 hidden 向量布局。

布局均为 `#ttg.blocked`；每格按 **sizePerThread；threadsPerWarp；warpsPerCTA；order** 列出完整参数。

| 配置 / 改动的 op | Gluon 基线 layout 参数 | Gluon 优化版 layout 参数 |
| --- | --- | --- |
| tokens=512/2048，H=1280 | `[4]；[64]；[4]；[0]` | `[8]；[64]；[1]；[0]` |
| tokens=512/2048，H=2560/4096 | `[4]；[64]；[4]；[0]` | `[16]；[64]；[1]；[0]` |
| tokens=1024，H=1280/2560/4096 | `[4]；[64]；[4]；[0]` | `[8]；[64]；[2]；[0]` |
| tokens=8192，H=1280/2560/4096 | `[4]；[64]；[4]；[0]` | `[8]；[64]；[1]；[0]` |

RMS 统计的结果是 scalar；Sigmoid/Sinkhorn 的 HC 小矩阵计算与 Post/Comb 输出也是 scalar，它们的布局没改。HC=2 分支保持不变。两版均 `num_stages=1 / waves_per_eu=1`。下表为 tokens×H×HC，输入 BF16。
