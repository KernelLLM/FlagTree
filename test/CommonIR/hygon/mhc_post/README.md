# mhc_post

## 1. 测试方法

- 在海光bw1000上进行测试。共三轮独立进程，每轮每版 20 次预热、50 个有效 GPU-event 样本。
- 每个 GPU-event 窗口重放 128 次 kernel，event 时间除以 128。编译、分配、参考计算、graph capture 及重置不计时；结果为热/复用工作集时延。
- 下表合并每版全部 150 个样本；时间单位为 μs，加速比为 TLE P50 / Gluon 优化版 P50。

## 2. 改变了哪些 op 的 layout

**算子顺序：Comb mix × Residual → 加上 Post mix × Layer output → 输出。**

改变的是 **Residual 混合和 Layer output 加权相加的 hidden 向量布局**；Residual/Layer output 读取、乘加及结果写回同步使用它。Comb/Post mix 系数是 scalar，不改布局。

布局均为 `#ttg.blocked`；每格按 **sizePerThread；threadsPerWarp；warpsPerCTA；order** 列出完整参数。

| tokens×H×HC | Gluon 基线 layout 参数 | Gluon 优化版 layout 参数 |
| --- | --- | --- |
| 4096×1280×2 | `[2]；[64]；[4]；[0]` | `[4]；[64]；[8]；[0]` |
| 4096×2560×2 / 4096×7168×2 | `[2]；[64]；[4]；[0]` | `[8]；[64]；[8]；[0]` |
| 32×1280×2 | `[1]；[64]；[4]；[0]` | `[1]；[64]；[2]；[0]` |

其余配置不变。对应 `BLOCK_H` 分别为 512→2048、512→4096、128→256。下表为 tokens×H×HC，输入 BF16。
