# hc_head_fused_kernel

## 1. 测试方法

- 在海光bw1000上进行测试。共三轮独立进程，每轮每版 20 次预热、50 个有效 GPU-event 样本。
- 使用 HIP graph 重放；tokens≤512 时每窗口 32 次，tokens≥1024 时每窗口 8 次。event 时间除以重复次数，仅计 kernel 计算。
- 下表合并每版全部 150 个样本；时间单位为 μs，加速比为 TLE P50 / Gluon 优化版 P50。

## 2. 改变了哪些 op 的 layout

**算子顺序：Residual 平方和与线性投影（第一遍） → 投影 RMS 归一化 → Sigmoid 生成 pre-mix → Residual 加权求和（第二遍） → 输出。**

改变的是 **第一遍的平方/投影计算及 hidden 归约，以及第二遍的 Residual 加权求和**。向量读取、逐元素计算和输出共用“向量布局”；第一遍的求和使用“归约输入布局”。优化将两者统一。

均为 `#ttg.blocked`，固定 `threadsPerWarp=[64], order=[0]`。下表每格按 **sizePerThread；warpsPerCTA** 列出另外两个参数。

| tokens×HC×H | 基线向量布局 | 基线归约输入布局 | Gluon 优化版统一布局 |
| --- | --- | --- | --- |
| 1×4×1280 / 2048×2×4096 / 4096×2×4096 | `[4]；[8]` | `[1]；[8]` | `[4]；[8]` |
| 4×4×2560 | `[2]；[8]` | `[1]；[8]` | `[2]；[4]` |
| 16×4×4096 / 64×4×7168 / 2048×4×4096 / 4096×4×4096 | `[2]；[8]` | `[1]；[8]` | `[4]；[8]` |
| 256×2×1280 / 512×2×1280 / 512×2×2560 | `[4]；[4]` | `[1]；[4]` | `[4]；[2]` |
