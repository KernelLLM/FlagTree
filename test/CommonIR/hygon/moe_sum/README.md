# moe_sum

## 1. 测试方法

- 在海光bw1000上进行测试。共三轮独立进程，每轮每版 20 次预热、50 个有效 GPU-event 样本。
- 每个 GPU-event 窗口重放 128 次 kernel，event 时间除以 128。编译、分配、参考计算、graph capture 及重置不计时；结果为热/复用工作集时延。
- 下表合并每版全部 150 个样本；时间单位为 μs，加速比为 TLE P50 / Gluon 优化版 P50。

## 2. 改变了哪些 op 的 layout

**算子顺序：读取 topk 路 Expert 输出 → 同一 hidden 元素逐路相加 → 输出。**

改变的是 **Expert 求和的 hidden 向量布局**，Expert 输出读取、FP32 累加和结果写回使用同一布局。topk 是固定展开的加法，不是 distributed reduce。

布局均为 `#ttg.blocked`；每格按 **sizePerThread；threadsPerWarp；warpsPerCTA；order** 列出完整参数。

| tokens×topk×H / dtype | Gluon 基线 layout 参数 | Gluon 优化版 layout 参数 |
| --- | --- | --- |
| 64×2×511 BF16 / 64×6×511 BF16 / 64×6×511 FP16 / 64×6×511 FP32 | `[1]；[64]；[4]；[0]` | `[1]；[64]；[2]；[0]` |
| 64×2×1024 BF16 | `[1]；[64]；[2]；[0]` | `[2]；[64]；[2]；[0]` |
| 64×6×128 BF16 / 64×6×128 FP16 | `[1]；[64]；[2]；[0]` | `[2]；[64]；[1]；[0]` |
| 64×6×1024 BF16 | `[1]；[64]；[8]；[0]` | `[2]；[64]；[2]；[0]` |
| 64×2×128 FP16 | `[1]；[64]；[8]；[0]` | `[2]；[64]；[1]；[0]` |
| 64×2×1024 FP16 / 64×6×1024 FP16 | `[1]；[64]；[4]；[0]` | `[2]；[64]；[2]；[0]` |
| 64×6×128 FP32 | `[1]；[64]；[2]；[0]` | `[1]；[64]；[1]；[0]` |
| 64×6×1024 FP32 | `[1]；[64]；[4]；[0]` | `[4]；[64]；[1]；[0]` |

未列出的配置保留基线布局。H=128 的单 wave 优化配置 tile=128，其余优化配置 tile=256；均 `num_stages=3 / waves_per_eu=1`。
