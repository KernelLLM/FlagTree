# fused_deepseek_v4_qnorm_rope_kv_rope_insert

## 1. 测试方法

- 在海光bw1000上进行测试。共三轮独立进程，每轮每版 20 次预热、50 个有效 GPU-event 样本

## 2. 改变了哪些 op 的 layout

- 512 维数据布局（Q/KV `gl.load`、Q square/sum/归一化、NoPE `gl.store`）：`BlockedLayout([4],[64],[2],[0])` → `BlockedLayout([8],[64],[1],[0])`。
- 32 维 RoPE 布局（cos/sin 与 even/odd 的 `gl.load`、旋转及 `gl.store`）：`BlockedLayout([1],[64],[2],[0])` → `BlockedLayout([1],[64],[1],[0])`。
- launch：`num_warps=2` → `1`；两版均 `num_stages=4 / waves_per_eu=1`。
