# mhc_bwd

## 1. 测试方法

- 在海光bw1000上进行测试。共三轮独立进程，每轮每版 20 次预热、50 个有效 GPU-event 样本。
- 每个 GPU-event 窗口重放 128 次 kernel，event 时间除以 128。编译、分配、参考计算、graph capture 及重置不计时；结果为热/复用工作集时延。
- 下表合并每版全部 150 个样本；时间单位为 μs，加速比为 TLE P50 / Gluon 优化版 P50。

## 2. 改变了哪些 op 的 layout

**算子顺序：Sinkhorn 梯度行/列统计 → 共轭梯度（CG）求解 → 梯度校正 → 梯度写回。**

**行/列统计、CG 求解和梯度校正共用的 token 向量布局**

- Gluon 基线：`#ttg.blocked<{sizePerThread = [1], threadsPerWarp = [64], warpsPerCTA = [4], order = [0]}>`。
- Gluon 优化版：`#ttg.blocked<{sizePerThread = [1], threadsPerWarp = [64], warpsPerCTA = [1], order = [0]}>`。

R/dR 读取、这些 op 的逐元素计算及梯度写回一起改为单 wave。这里的 layout 分布的是 token，不是 4×4 矩阵的行/列；HC 维求和是显式加法，没有沿 token 的 reduce。`num_warps=4` → `1`，均 `num_stages=2 / waves_per_eu=1`，CG 迭代次数不变。下表为 tokens×4×4，输入 FP32。
